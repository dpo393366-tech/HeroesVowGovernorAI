도독 AI · 국고 물품 분배 · 자동 등용 — 먼저 읽어 주세요

[설치]
1. 게임을 저장하고 종료합니다.
2. 받은 ZIP을 완전히 풀고 GovernorAI 폴더를 엽니다.
3. install.bat를 두 번 클릭합니다. 다른 파일과 payload 폴더도 같이 두세요.
4. 게임 경로가 하나 나오면 Enter, 여러 개면 번호를 입력하고 Enter를 누릅니다.
   못 찾으면 B + Enter를 누르고 게임의 ThreeKingdom.exe를 선택하세요.
5. install 완료 또는 이미 요청한 상태입니다 문구를 확인합니다.
6. 평소처럼 게임을 실행하고 F12 → 도독 AI를 엽니다.
BepInEx가 없으면 자동 설치합니다. 처음 설치할 때 인터넷이 필요합니다.
상세 설치법: INSTALL.ko.md

[어떻게 달라지나요?]
도시 목표를 고려한 건설·수리·업그레이드·재건축·연구, 국경 위험과 능력을 고려한 장수 배치, 여러 도시의 전쟁 지원·군량 보급·초과 병력 분산, 전투 종료 후 부대 재판단을 보완합니다.
건물은 현재 해금된 후보와 실제 부지로 연속 계획을 짭니다. 목표·민심/치안/인구 증감·병영 상한·농업/상업·인접 효과 등을 고려하고, 연구 해금이나 도시 확장 후 다시 계획합니다. 농업/상업 구역을 무조건 분리하지 않습니다.

[F12 설정]
국고 분배: 돈을 나누는 기능이 아니라 국고 물품을 장수에게 주는 기능입니다.
상위50%는 장수 능력 순위 상위 절반을 대상으로 한다는 뜻입니다. 예: 주인공 제외20명이면 상위10명. 전원 대상은100%입니다.
장수마다1개씩 순환합니다. 성장 소비품은 성향을 보고, 장비는 현재보다 확실히 개선되는지 확인합니다. 설정 변경은 다음 자동 실행부터 적용합니다.
자동 등용: 전체/남성만/여성만 → 인원 입력 → 예약 등록. 등록 순서대로 하나씩 실행하고 실제 성공 인원을 셉니다. 중지/재개/X취소가 가능합니다.
보고 설정: 일반 입성·수용량 초과 보고를 각각 켜고 끕니다. 수용량 규칙 자체를 없애지는 않습니다.
전체 설명과 건물 심시티 상세 기준: GUIDE.ko.md

[업데이트·제거]
설치 후 게임 시작 시 자동 업데이트합니다. 자동 업데이트가 없던 구 설치본은 이번 ZIP을 한 번 직접 설치해야 합니다.
제거는 게임을 종료하고 remove.bat를 실행합니다. 이 모드와 자동 업데이트 파일을 제거하고 BepInEx·다른 모드·설정·저장은 유지합니다.
