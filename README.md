# 도독 AI · 국고 분배 · 자동 등용

Heroes' Vow / 입지전용 독립 통합 모드입니다. 도독 AI, 국고 분배, 자동 등용 큐를 묶고 F12에서 설정합니다.

**[설치 파일 다운로드](https://github.com/dpo393366-tech/HeroesVowGovernorAI/releases/latest)** · **[상세 사용 설명](GUIDE.ko.md)**

## 포함 구성

| 구성 | 버전 | 역할 |
|---|---|---|
| StrategicSupport | 1.5.43 | 도독 AI, 자동 등용 큐, 보고 제어 |
| TreasuryAwards | 1.4.3 | 국고 물품 분배 |
| HeroesVowSettings | 1.4.0 | F12 설정 창 |
| GovernorAutoUpdate | 1.0.0 | 모드 로딩 전 자동 업데이트 |

조우(FieldEncounters), 군단전 예비대(ReserveWaves), 군단전 내부 AI 컨트롤은 포함하지 않습니다. 예비대를 따로 설치하면 해당 모드가 제공하는 병력 손실·지원 도착 예측 정보를 선택적으로 활용하며, 미설치 상태에서도 도독 AI는 동작합니다.

## 설치 및 제거

1. 설치 ZIP을 준비합니다. BepInEx IL2CPP가 없으면 공식 배포처에서 자동으로 설치하고, 이미 있으면 기존 로더를 사용합니다.
2. 진행을 저장하고 게임을 종료합니다.
3. 릴리스의 `HeroesVow_GovernorAI_Standalone.zip`을 풀고 `GovernorAI/install.bat`를 실행합니다.
4. 게임 폴더를 자동 탐색하며, 찾지 못하면 직접 지정합니다. 실행 후 F12로 설정합니다.

제거는 같은 폴더의 `remove.bat`입니다. 설정·저장 파일은 유지하고 이 패키지의 DLL만 해제합니다. 교체 전 DLL은 게임의 `BepInEx/independent-backups`에 백업합니다. 기존 버전 제한 없이 백업 후 교체하며, 같은 이름의 중복 DLL도 정리합니다. 구버전 DLL을 다른 이름으로 추가 복사하지 마세요.

배포 ZIP에는 게임 파일이나 BepInEx 자체가 포함되지 않습니다. 로더가 없을 때만 공식 IL2CPP x64 배포본을 내려받으므로 최초 설치에는 인터넷이 필요합니다. 게임 메타데이터 해시나 기존 DLL 버전 차이로 설치를 막지 않으며 파일 손상 검사·실행 중 교체 방지·실패 복원은 유지합니다. 게임 업데이트로 내부 기능이 바뀌면 별도 호환 수정이 필요할 수 있습니다. **이 설치본을 한 번 설치하면 이후 게임 시작 시 GitHub 최신 파일을 자동 확인·적용합니다. 이전 자동 업데이트 미포함 설치본 사용자는 이번 ZIP을 한 번 직접 설치해야 합니다.** 같은 버전 번호로 재배포한 수정도 감지합니다.

## 게임 시작 시 자동 업데이트

BepInEx가 게임 모드를 불러오기 전에 도독 AI·국고·설정 세 파일을 함께 확인하고 적용합니다. 업데이트를 받으면 같은 실행에 적용되므로 별도 재시작이 필요하지 않습니다. 인터넷 실패나 GitHub 제한 시 기존 파일로 계속 시작하며, 손상된 파일은 적용하지 않고 교체 오류 시 백업으로 복원합니다. 다른 모드와 설정·저장은 바꾸지 않습니다.

버전 확인은 최대 5초, 확인과 다운로드는 합쳐 최대 15초의 네트워크 대기 제한을 둡니다. 실제 파일 검증·복원 시간은 별도입니다. 자동 확인을 끄려면 게임 종료 후 `BepInEx/config/local.heroesvow.governor.updater.cfg`의 `[Update]` 아래 `Enabled = false`로 설정하세요. 기록은 `BepInEx/GovernorAI-update.log`에 남습니다.

## v1.5.43 변경점

- 지원 중 전투가 끝나면 임시 야영 판단과 새 귀환 목표가 충돌해 명령이 누락되던 문제를 수정했습니다. 대기 중인 판단도 같은 부대의 최신 목표를 읽습니다.
- 대기열에 판단을 넣지 못했는데도 당일 처리 완료로 기록하던 부분을 수정했습니다.
- 업무·출정 중인 장수를 소속 도시의 배치 인원에 포함하고, 평상시 한 명 차이를 메우는 이동은 줄였습니다. 빈 도시의 최소 인력과 점령지·위협 지역 충원은 유지합니다.
- BepInEx 자동 설치·기존 로더 재사용과 상세 사용 설명을 추가했습니다.

## 주요 기능

- 내정·건설·수리·업그레이드·재건축·연구 판단, 도시 목표와 해금 건물 변화에 따른 배치 계획.
- 장수·병력·군량 분배, 다도시 지원 및 전투 후 부대 재판단. 같은 세력의 도독 관할 경계를 넘어 분배합니다.
- 플레이어 소속 세력은 기본 1일, NPC는 3일 주기입니다. 계산은 분산 처리하므로 모든 명령이 날짜 변경 순간에 동시에 실행되는 방식은 아닙니다.
- 직접 내린 명령은 완료 후 5일 동안 보호하며, 해산 시에는 즉시 AI 관리 대상으로 돌아갑니다.
- F12 **국고 분배**: 능력 순위에 따른 대상 비율 조절. 한 장수에게 몰아주기보다 한 번씩 순환하며 바닐라 상벌 한도를 따릅니다.
- F12 **자동 등용**: 남성·여성·전체 조건과 인원을 지정한 순차 큐. 큐별 중지·재개·취소가 가능하며 맨 위 큐가 끝나야 다음 큐가 실행됩니다. 완료는 시도 횟수가 아닌 실제 등용 인원으로 셉니다.
- F12 **보고 설정**: 일반 부대 입성 보고와 병력 수용량 초과 보고를 각각 켜고 끕니다. 이미 표시되거나 대기 중인 알림까지 삭제하지는 않습니다.

## 검증 범위

실제 게임 참조 빌드, Harmony 연결 계약 검사, AI·국고·등용 큐·설정 창 모의 회귀검사를 수행했습니다. 분리 패키지는 독립/조합 설치·제거와 파일 해시를 검사했습니다. 이 결과는 실제 장기 플레이에서 모든 상황이 검증됐다는 뜻이 아닙니다. 분리본의 실제 화면·전투 동작은 추가 확인이 필요하며, 전역 최적 배치나 무결점을 보장하지 않습니다.

자동 업데이트는 실제 BepInEx 로더를 격리된 폴더에서 실행하여 기존 1.5.42 DLL을 GitHub의 1.5.43으로 교체하는 것을 확인했습니다. 게임 본체를 실행한 검증과는 구분됩니다.

## 소스 빌드

Windows PowerShell, .NET 6 SDK/런타임, .NET SDK 7 이상 및 지원 게임의 BepInEx/interop 참조가 필요합니다. 기존 배포는 SDK 7.0.203과 .NET 6.0.16 참조로 빌드했습니다. 게임/BepInEx DLL은 각자의 설치본에서 참조합니다.

```powershell
.\Build.ps1 -GameDir 'D:\SteamLibrary\steamapps\common\LegendOfHeros'
.\Test.ps1 -GameDir 'D:\SteamLibrary\steamapps\common\LegendOfHeros'
```

빌드는 `src/StrategicSupport`, `src/TreasuryAwards`, `src/Settings`에 DLL을 생성하며 게임 파일은 바꾸지 않습니다. `Test.ps1`은 모의검사와 실제 게임 메서드 서명 검사를 수행하며 게임을 실행하지 않습니다. 과거 고장 DLL을 사용하는 내부 음성 대조군 검사는 공개 소스에 그 바이너리를 넣지 않아 제외했습니다. 설치용 ZIP은 릴리스 자산을 사용하세요. `installer`는 설치기 소스이며 `payload` 바이너리는 릴리스 ZIP에만 포함합니다.
