# 도독 AI · 국고 물품 분배 · 자동 등용

입지전에서 **도시 운영, 장수 배치, 전쟁 지원과 전투 후 처리를 자동으로 판단**하고, **국고의 물품을 장수에게 분배하거나 원하는 조건으로 장수를 등용 예약**하는 모드입니다.

**[설치 파일 바로 받기](https://github.com/dpo393366-tech/HeroesVowGovernorAI/releases/latest/download/HeroesVow_GovernorAI_Standalone.zip)** · **[처음 설치하는 방법](INSTALL.ko.md)** · **[기능별 상세 설명](GUIDE.ko.md)**

## v1.5.44 변경점

- 건물 완공이나 도시 목표 수치 변화로 건설 계획이 계속 취소되던 문제를 수정했습니다. 계획 계산의 대기도 줄였습니다.
- 한 도시의 전력이 부족하면 여러 도시의 병력을 집결 도시에 모아 할거군 토벌을 준비합니다.
- 수용량 초과 병력 이송 시, 출발지 군량이 부족하면 다른 도시에서 도착지 군량을 지원하도록 보완했습니다. 병력보다 늦는 보급은 이송 허가에 포함하지 않습니다.
- 국경 방어를 유지할 수 있는 경우 병력이 많은 부대부터 이송해, 제한된 수용 공간으로 손실을 줄입니다.
- 수송 출발·도착·취소 및 실제 병력·군량 입고 기록을 추가했습니다.

## 처음 설치한다면

1. 게임을 저장하고 **종료**합니다.
2. 위 링크에서 **`HeroesVow_GovernorAI_Standalone.zip` 하나**를 받습니다. `source.zip`이나 `Source code`는 설치용이 아닙니다.
3. ZIP을 **완전히 압축 해제**하고 `GovernorAI` 폴더를 엽니다.
4. **`install.bat`를 두 번 클릭**합니다. 다른 파일과 `payload` 폴더도 함께 두세요.
5. 설치 창에 게임 경로가 하나 나오면 **Enter**, 여러 개면 **번호 + Enter**를 누릅니다. 못 찾으면 **B + Enter**를 누르고 `ThreeKingdom.exe`를 선택하세요.
6. **`install 완료`** 또는 **`이미 요청한 상태입니다.`**를 확인한 뒤 창을 닫습니다.
7. 평소처럼 게임을 실행하고 **F12 → 도독 AI**를 엽니다.

BepInEx는 모드를 실행하는 로더입니다. **없으면 설치기가 자동 설치하고, 이미 있으면 그대로 사용합니다.** 처음 로더를 설치할 때는 인터넷이 필요합니다. 게임 폴더에 파일을 하나씩 복사할 필요는 없습니다.

설치 후에는 게임 시작 때 최신 파일을 자동 확인합니다. **자동 업데이트가 없던 예전 설치본은 이번 ZIP으로 한 번 직접 설치해야 합니다.** 같은 버전 번호로 수정본을 올려도 감지합니다.

## AI가 어떻게 바뀌나요?

게임의 기존 건설·이동·출정 명령을 이용하면서, 아래 판단을 추가로 수행합니다. 플레이어가 속한 세력과 일반 NPC 세력에 적용되며, 같은 세력에서는 도독 관할을 넘어 지원과 분배를 검토합니다.

| 상황 | 이 모드가 추가로 판단하는 것 |
|---|---|
| 도시 목표를 채워야 함 | 목표 건물과 수치의 부족분을 확인하고 건설·필요 연구·업그레이드·재건축을 검토합니다. |
| 연구가 끝나 새 건물이 열림 | 새 건물을 후보에 넣어 배치를 재평가하고 기존 저효율 건물을 대체할지 판단합니다. |
| 도시가 확장됨 | 늘어난 부지와 건물 상한에 맞춰 건설 계획을 다시 짭니다. |
| 적이 접근하거나 아군 전투가 열세임 | 실제 도로와 도착 예상, 병력 소모, 다른 국경의 방어를 함께 보고 선발대·후속 지원을 검토합니다. |
| 한 전투에 병력이 너무 몰림 | 적의 추가 도착 병력까지 고려한 뒤 다른 전투 지원이나 귀환·분할을 검토합니다. |
| 지원하러 가던 전투가 끝남 | 사라진 목표로 계속 가거나 멈춰 있지 않도록 새 지원 목표·진격·귀환을 다시 판단합니다. |
| 도시 병력이 수용량을 넘음 | 다른 아군 도시의 수용 여력과 경로를 확인해 분산을 검토합니다. |
| 점령지에 장수가 부족함 | 필요한 일손과 국경 위험을 따져 장수를 충원하고, 조건에 맞으면 빈 태수 자리를 채웁니다. |
| 후방에 좋은 장수가 몰림 | 인원과 능력을 함께 비교해 국경에는 전투 능력, 내부에는 내정 역할을 고려하여 배치합니다. |
| 사병을 키우는 가문 장수가 자꾸 전근감 | F12 → 장수 배치에서 육성 중 보호 또는 가문 전체 제외를 선택합니다. 육성 중 보호는 완료 후 자동 해제됩니다. |
| 책략점수·외교 기회가 생김 | 효과와 비용·실행 조건을 평가해 책략·외교·계략과 포로 구출 수단을 검토합니다. |

**기본 판단 기준은 아군 1일, NPC 3일**입니다. 실제 명령은 나누어 처리하며 인력·경로·자금 등의 실행 조건을 확인합니다. 지원이 필요하다고 해서 이동 시간을 건너뛰거나 무조건 출발시키지는 않습니다.

직접 내린 명령은 모드가 추적하는 범위에서 수행 중 보호하고, 완료 후 5일 동안 추가 명령을 기다립니다. **부대 해산 시에는 즉시 AI 관리로 돌아갑니다.** 안병부동·공격 세력 지정·연구 금지 등 관련 바닐라 지침도 확인합니다.

## 건물 심시티는 이렇게 진행됩니다

**현재 해금된 공공 건물과 실제 부지로 ‘무엇을 어디에 어떤 순서로 지을지’ 계획을 만들고, 상태가 바뀌면 다시 평가합니다.** 농업 구역·상업 구역을 무조건 분리해 놓는 방식은 아닙니다.

- **도시 목표부터 확인:** ‘특정 건물 2개’, 농업·상업 수치, 수입 등 부족한 조건을 건설 후보의 우선순위에 반영합니다.
- **민심·치안·인구의 평상시 증감을 확인:** 현재 수치가 높아도 매달 줄어드는 배치는 피하도록 평가합니다. 목표 건물에 부작용이 있으면 이를 보완할 시설을 먼저 지어야 할 수 있습니다.
- **병영 상한 확보:** 현재 도시 규모와 해금 상태에서 지을 수 있는 병영의 부족분을 따집니다. 건설 중인 병영도 세어 중복 건설을 줄이며, 병영보다 덜 중요한 건설·선택적 업그레이드는 후순위로 미룹니다.
- **농업·상업과 효과 건물의 조합:** 직접 수입뿐 아니라 인접·구역 보너스, 연구·책략·탐색·모집 등의 효과도 비교합니다. 혼합 배치가 더 유리하면 같은 구역에 섞어 짓는 후보도 사용합니다.
- **남는 부지와 성벽 확인:** 작은 빈칸과 성벽 설치 자리도 후보를 찾습니다. 단순히 ‘화살탑이 몇 개 있으니 충분’이라는 고정 개수로 멈추는 방식은 아닙니다.
- **변화에 맞춰 재계획:** 연구 해금, 도시 확장, 목표·건물 상태가 바뀌면 남은 계획을 재평가하고 철거·대체도 검토합니다.

예를 들어 ‘도박장 2개’가 목표라면 **도박장 하나를 업그레이드하는 것과 두 개를 짓는 것은 다른 조건**으로 취급합니다. 구제소가 필요하지만 아직 잠겨 있으면 해금 조건과 연구를 검토하고, 해금 후 자리가 없으면 기존 건물을 바꿀 수 있는지 검토합니다.

철거는 이미 달성한 목표, 병력 수용량, 필요한 생산·기능이 무너지는지 확인한 뒤 진행합니다. 모든 건물을 한꺼번에 허무는 방식은 아닙니다. **[배치 순서·철거·업그레이드의 상세 기준 보기](GUIDE.ko.md)**

## 국고 분배는 무엇을 나누나요?

**국고에 보관된 장비·성장 소비품 등의 물품을 아군 장수에게 줍니다.** F12의 퍼센트는 **물품을 받을 장수의 능력 순위 범위**입니다.

| 예시: 주인공을 제외한 비교 대상 장수가 20명일 때 | 분배 대상 |
|---|---|
| 상위 50% | 능력치 합계 상위 10명 |
| 상위 80% | 상위 16명 |
| 상위 100% | 20명 전원 |

소수점 인원은 올림합니다. 기본값은 50%이며 기존에 바꾼 설정은 유지됩니다. **‘50%’는 국고 돈이나 물품의 절반을 쓰라는 뜻이 아닙니다.** 포로 등 실제 지급할 수 없는 장수는 건너뜁니다.

지급은 한 장수의 월별 칸을 먼저 꽉 채우기보다 **A에게 하나 → B에게 하나 → C에게 하나 → 다음 바퀴** 식으로 순환합니다. 처리량 때문에 중단되면 다음 실행에서 순서를 이어갑니다.

장비는 현재 장비의 능력이나 부여된 혼을 떨어뜨리지 않으면서 개선되는지를 확인합니다. 기존 무기를 바꿀 때는 같은 종류를 비교합니다. 성장 소비품은 무력·지력 성향에 맞는 것을 먼저 검토하고, 그 밖의 물품은 가격 등 정렬 기준으로 검토합니다. 단순히 가격이 높다는 이유만으로 나쁜 장비로 교체하지 않습니다.

**설정:** F12 → 도독 AI → 국고 분배 → **‘분배 대상 · 능력치 상위 (%)’** 조절. 다음 자동 분배부터 적용되며 재시작은 필요 없습니다. 게임의 상벌 창에 추가된 **‘국고 분배’** 버튼으로 수동 실행할 수도 있습니다.

## 자동 등용 예약은 어떻게 쓰나요?

F12 → 도독 AI → **자동 등용**에서 성별을 고르고 목표 인원을 입력한 뒤 **예약 등록**을 누릅니다.

예를 들어 ‘여성만 30명’을 먼저 등록하고 ‘전체 10명’을 추가하면 **여성 30명이 실제로 합류한 뒤** 다음 예약을 실행합니다. 동시에 돌리지 않습니다. 재야 장수와 포로 중 능력과 실행 가능성을 고려해 대상을 고릅니다.

예약 카드에는 상태·성공 인원·진행 중 임무가 표시됩니다. **중지/재개**로 조절하고 **X**로 취소합니다. 선두 예약을 중지하면 뒤의 예약도 기다립니다. X를 누르면 새 파견을 멈추고 이미 진행 중인 임무를 정리한 뒤 다음 예약으로 넘어갑니다. 목표 인원이 채워지면 게임 알림을 표시합니다.
